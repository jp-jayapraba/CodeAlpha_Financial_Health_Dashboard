# CodeAlpha Financial Health Dashboard

## 📊 Project Overview

This project is a Financial Health Dashboard developed using Microsoft Power BI as part of the CodeAlpha Internship – Task 1.

The dashboard helps visualize and analyze an organization's financial performance through interactive reports and charts.

## 🎯 Objectives

- Analyze revenue and expenses
- Track profit and profit margin
- Visualize monthly financial trends
- Analyze expenses by category
- Present financial statements
- Analyze cash flow
- Provide revenue forecasting for financial planning

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

## 📈 Dashboard Features

### Page 1 – Financial Dashboard

- Total Revenue
- Total Expenses
- Total Profit
- Profit Margin %
- Monthly Revenue vs Expenses
- Expenses by Category
- Revenue Forecast

### Page 2 – Financial Statements

- Income Statement
- Balance Sheet
- Cash Flow Statement

## 📁 Dataset

The project uses a sample financial dataset containing:

- Transactions
- Balance Sheet
- Cash Flow

## 💡 Key Insights

The dashboard provides a simple interactive view of financial performance and helps users understand revenue growth, expense distribution, profitability, cash flow, and forecasted revenue.
